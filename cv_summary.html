AI Workforce — Enterprise Multi-Tenant Multi-Agent AI Platform

Role: AI Engineer / Backend AI Engineer

Description

Built an enterprise multi-agent AI platform where each specialized agent (HR, Legal, IT, Finance, Knowledge) acts as a role-based AI employee with RBAC-enforced tool access, structured intent routing, and Human-in-the-Loop approval workflows, deployed as a production microservice architecture.

Tech Stack

Python 3.11, FastAPI, SQLAlchemy, PostgreSQL + pgvector (HNSW), Redis, Qwen/Qwen3-Embedding-0.6B, BAAI/bge-reranker-v2-m3, OpenAI, Gemini, Hugging Face, Next.js 16, TypeScript, Docker, GitHub Actions

CV Bullet Points

  • Multi-Agent Orchestration (AI Workforce): Built a CEO Orchestrator Agent that decomposes requests into DAG task plans and delegates to specialized AI Agents (HR, Legal, IT, Finance, Knowledge) with RBAC-controlled toolsets.
  • Hybrid RAG Pipeline (AI Workforce): Implemented end-to-end RAG covering semantic chunking, SHA-256 deduplication, batched embedding (Qwen3-Embedding-0.6B, 1024-dim), and Reciprocal Rank Fusion over dense (pgvector HNSW) and sparse (BM25/FTS) retrieval.
  • CrossEncoder Reranking (AI Workforce): Integrated BAAI/bge-reranker-v2-m3 with sigmoid normalization, weighted score fusion (90% model + 10% retrieval prior), CUDA OOM-safe batch sizing, and automatic lexical fallback.
  • Intent Classification (AI Workforce): Designed a deterministic intent classifier routing queries to SQL tools, RAG pipeline, or clarification flow, with per-tool RBAC validation before every execution.
  • AI Microservice (AI Workforce): Developed a stateless FastAPI service for embedding, reranking, and LLM generation supporting OpenAI, Gemini, and local Hugging Face models — fully decoupled from business logic and database access.
  • Multi-tenant Architecture (AI Workforce): Enforced tenant isolation, document-level RBAC ACL, Human-in-the-Loop approval workflows, full audit logging, and token-level cost metering per session and agent.
  • RAG Evaluation (AI Workforce): Built a custom evaluation framework measuring Recall@K, MRR, and NDCG@K with per-request observability metadata (latency, fallback flag, candidate count).
